# AI工具调研项目-2025

## 项目概述
本项目旨在全面调研2025年最值得关注的AI工具，为用户提供详细的工具分析和选择建议。

## 项目结构
```
AI工具调研项目-2025/
├── README.md           # 项目说明文档
├── .gitignore         # Git忽略文件配置
├── screenshots/       # 网站截图存储
├── reports/           # 分析报告存储
└── data/             # 原始数据存储
```

## 调研方法
1. 使用Brave Search搜索最新AI工具信息
2. 访问权威网站收集第一手资料
3. 截图保存重要页面内容
4. 分析工具特点、价格、使用场景
5. 生成对比表格和推荐报告

## 调研目标
- 识别2025年最值得关注的TOP10 AI工具
- 分析各工具的优势和适用场景
- 为用户提供个性化的工具选择建议
- 制定AI工具学习和应用计划

## 创建时间
2025年7月9日

## 使用说明
1. 查看 `reports/` 文件夹中的分析报告
2. 浏览 `screenshots/` 文件夹中的网站截图
3. 参考 `data/` 文件夹中的原始数据
